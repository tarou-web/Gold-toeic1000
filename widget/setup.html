ウィジェットの設置

  1. App Storeで Scriptable（無料）を入れる
  2. 下の緑のボタンでコードをコピーする
  3. Scriptableを開き、右上の ＋ で新しいスクリプトを作り、コピーしたコードを貼り付ける。上の名前を フレーズ1000 にして「Done」
  4. ホーム画面を長押し → 左上の 編集 → ウィジェットを追加 → Scriptable を選んで、小（または中）サイズを追加
  5. 追加したウィジェットを長押し → ウィジェットを編集 → Script で「フレーズ1000」を選ぶ
  6. 同じ画面の Parameter に、フレーズアプリの一番下にある「あなたの合言葉」を貼り付ける
読み込み中…

このコードは一度貼り付ければ、絵や表示が更新されても貼り直す必要はありません。

ウィジェットの更新タイミングはiPhoneが決めるため、学習してから数字が変わるまで少し時間がかかることがあります。
