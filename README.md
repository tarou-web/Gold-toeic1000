# TOEICフレーズ1000

TOEIC頻出フレーズ1000個を、回転する単語カード・4択クイズ・一覧で覚える暗記アプリです。

## iPhoneのホーム画面に追加する
1. このサイトのURLをSafariで開く
2. 共有ボタン →「ホーム画面に追加」
3. 「Webアプリとして開く」をオンにして追加

学習記録は端末のブラウザ内に保存されます。

## 中身を変更するとき
`src/template.html`（画面）と `src/data.json`（フレーズ）を編集し、リポジトリの一番上で `python3 src/mksite.py` を実行すると `index.html` が作り直されます。
